# CodSoft Data Analytics Internship - Task 2

## Exploratory Data Analysis (EDA)

This project was completed as part of my CodSoft Data Analytics Internship.

## Objective

The objective of this task is to explore customer sales data,
identify patterns, analyze missing values, detect outliers,
and generate useful business insights.

## Dataset

The dataset contains:

- Customer ID
- Age
- Gender
- City
- Product Category
- Purchase Amount
- Purchase Frequency
- Rating
- Purchase Date

## Technologies Used

- Python
- Pandas
- Google Colab
- Jupyter Notebook

## Analysis Performed

- Dataset exploration
- Data types and shape analysis
- Missing value analysis
- Descriptive statistics
- Categorical analysis
- City-wise sales analysis
- Product category-wise sales analysis
- Outlier detection using IQR
- Correlation analysis
- Business insights

## Conclusion

The analysis provides insights into customer purchasing
behavior, sales patterns, and unusual transactions.
